# SOURIOU_Yanis_PLAT_JV2

Les touche sont présente dans le jeu, cependant les voici si nécessaire :
- **ZQSD** pour ce déplacer
- **Espace** pour sauter
- **Échap** pour mettre pause
- **Click Gauche** pour tirer avec le grapin

Les difficultés ont été : 
- le code du grapin pour qu'il tourne autour du personnage selon la direction de ce dernier.
- le code des plateform mouvante, pour pouvoir emmener le joueur avec elles lorsqu'il s'y accroche.
- le level design.

J'ai eu de plus un problème personnel technique, j'ai été obligé à cause des vacance de fin d'année de finir le projet sur mon pc portable, or celui ci ne me permet pas de tester mon jeu (il n'est pas assès puissant pour unreal) j'ai donc écourter le jeu et enlever une mécanique qui permetait de se transformer a notre guise. Je n'ai aussi pas pu vraiment exploter le grapin est c'est mécanique.
